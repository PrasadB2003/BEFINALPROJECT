# 🎙️ Speech Emotion Recognition using Deep Learning  

This project focuses on **speech emotion recognition (SER)**, where the goal is to classify human emotions from audio signals using machine learning and deep learning techniques.  

It is trained on the **TESS Toronto Emotional Speech Set (TESS Dataset)** and extracts meaningful **audio features** (MFCCs, chroma, spectral contrast, etc.) from speech samples. A **Deep Neural Network (DNN)** is trained to classify emotions like *happy, sad, angry, neutral, fearful, disgust, surprise*.  

The project also supports **real-time emotion prediction** from live audio input and includes visualization of training metrics and model architecture.
